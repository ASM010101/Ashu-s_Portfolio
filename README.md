## 🧭 Creative Concept & Information Architecture

The central creative motif is **an AI engineer's research sketchbook coming alive as an autonomous machine**. Rather than standard static cards or marketing templates, the portfolio is structured as a continuous executing system:

1. **`00 / BOOT`**: Cold system initialization, precision technical text, hand-drawn marginalia, workstation revealing the stylized researcher avatar.
2. **`01 / SEE`**: Spatial perception, OCR, and computer vision. Interactive document bounding box scanning (Video KYC) & UAV obstacle avoidance path-planning (IEEE 2024 paper).
3. **`02 / RETRIEVE`**: Semantic memory and Retrieval-Augmented Generation. Live vector embedding lookup, cosine similarity clustering, and dense + BM25 hybrid re-ranking.
4. **`03 / ACT`**: Agentic AI and autonomous tool execution. Multi-agent decomposition using Google ADK and custom Model Context Protocol (MCP) servers.
5. **`04 / SPEAK`**: Speech AI and acoustic waveform synthesis. Code-switching multilingual TTS and speech-to-speech accent translation via an encoder-mapper-vocoder pipeline.
6. **`05 / GENERATE`**: Latent space diffusion. Interactive denoising progression ($t = 50 \to 0$) conditioned via ControlNet geometry, IP-Adapter features, and LoRA fine-tuning (IndiaAI Mission & HyperVerge research).
7. **`06 / VERIFY`**: Automated evaluation gates, pre-release regression checks, and deterministic guardrail validators.
8. **`07 / RESEARCH`**: Unfolded manuscripts and architectural blueprints for peer-reviewed IEEE and Taylor & Francis ICICS 2025 papers.
9. **`08 / FIELD LOG`**: Production checkpoints at Samespace (SDE-1 AI/ML Engineer, Intern) and research fellowships at HyperVerge Nexus & IndiaAI Mission.
10. **`09 / TOOLBOX`**: Frameworks, compilers, vector databases, and tools mapped to their physical system domains, plus Oracle Cloud Generative AI certification.
11. **`10 / MISSIONS`**: Standard Chartered Video KYC & Barclays Financial Anomaly Detection hackathon prototypes.
12. **`11 / ORIGIN`**: Academic vector from SRM Institute of Science & Technology (B.Tech, CGPA 9.04/10.00) to IIT Patna (M.Tech in Artificial Intelligence).
13. **`12 / SHIP`**: System ready signal, contact gateway, verified GitHub, LinkedIn, and PDF resume links.

## ⚡ Key Features

- **Recruiter Mode**: One-click instant toggle to transform the experience into an information-first, accessible executive candidate summary.
- **60-Second Guided Tour**: Autopilot walkthrough navigating critical engineering nodes with Pause, Skip, and Exit controls.
- **Hidden Command Palette (`Cmd/Ctrl + K`)**: Keyboard-driven terminal with instant navigation and interactive easter eggs (`whoami`, `matrix`, `lora`, `confetti`).
- **Developer Debug Telemetry (`Ctrl + Shift + D`)**: Real-time FPS monitor, viewport metrics, scroll velocity, active node, and WebGL capability tiering.
- **Procedural Web Audio**: Zero external audio downloads. All acoustic feedback is synthesized procedurally on-the-fly using the native Web Audio API (muted by default).
- **Capability Tiering & Fallbacks**:
  - **Level 2**: Full 3D particle fields, cel-shaded avatar, and camera choreography.
  - **Level 1**: Lightweight 2.5D canvas for lower-power devices.
  - **Level 0**: Graceful DOM/SVG fallback with zero broken UI if WebGL is unavailable or reduced-motion is requested.

## 🚀 Deployment

The site is configured for automatic deployment to **GitHub Pages** via GitHub Actions upon push to `main`:

```bash
git add .
git commit -m "feat: complete interactive AI engineering sketchbook portfolio"
git push origin main
```

Static build outputs are routed to `dist/` with relative asset paths (`base: './'`).

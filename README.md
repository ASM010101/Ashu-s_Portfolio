## 🧭 Interactive Experience Architecture

The portfolio is structured around an infinite hand-drawn 3D corridor and stylized thematic rooms:

1. **The Entrance & Corridor**:
   - Dynamic tearing-paper preloader with smooth exit transitions.
   - Hand-sketched 3D corridor with character avatar, split-letter typography (`ASHISH`), and interactive doors.
2. **The Gallery (Projects & Research)**:
   - Walkable 3D exhibition of peer-reviewed research papers and hackathon systems.
   - **IEEE (Jun 2024)**: *Obstacle Detection in Path Planning for Unmanned Aerial Vehicles Based on YOLO*.
   - **Taylor & Francis ICICS 2025**: *ICIP: An Integrated Approach for AI Image Generation Using Stable Diffusion*.
   - **Standard Chartered Hackathon**: Online Video KYC System.
   - **Barclays Hackathon (Finalist)**: Financial Anomaly Detection System.
3. **The Sky Room (About Me & Milestones)**:
   - Infinite paper-airplane cloud flight through career milestones.
   - IndiaAI Mission & HyperVerge Nexus Research Fellowships.
   - SRM IST B.Tech CSE AI & ML (CGPA 9.04) & IIT Patna M.Tech AI.
   - Samespace SDE-1 AI/ML Engineer production deployments.
   - Interactive pop-able skill balloons and Oracle Generative AI certification showcase.
4. **The Studio (AI Lab & Deep Dives)**:
   - Interactive 3D monitor tower featuring CRT TVs, desktop monitors, and mobile displays with research deep dives and technical architectural breakdowns.
5. **The Contact Room (Message in a Bottle)**:
   - Interactive 3D ocean pier with floating social barrels connecting directly to LinkedIn, GitHub, Resume PDF, and Email.
   - Interactive message-in-a-bottle rolling and throwing animation with anti-spam security.

## 🛠️ Technology Stack

- **Core**: React 19, Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animation & Motion**: GSAP (GreenSock), ScrollTrigger, Observer, TextPlugin
- **Styling**: Vanilla SCSS / CSS Modules, hand-drawn design tokens, responsive typography
- **Optimization**: WebP textures, GLSL brush-reveal shaders, compression plugin, SEO structured schema (JSON-LD), and `llms.txt`

## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/ASM010101/Ashu-s_Portfolio.git
cd Ashu-s_Portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Production build
npm run build

# 5. Preview production build
npm run preview
```
